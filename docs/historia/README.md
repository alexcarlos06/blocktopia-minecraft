# História de Blocktopia

Esta pasta organiza a aventura inicial para revisão. Os textos narrativos são uma proposta editorial baseada no pedido atual e no plano versionado; não são transcrição dos textos locais citados no histórico nem evidência de implantação.

## Leitura e responsabilidade de cada documento

| Documento | Conteúdo |
| --- | --- |
| [Contexto e decisões](CONTEXTO-E-DECISOES.md) | Fontes disponíveis, premissas e decisões pendentes |
| [Capítulo 1 — O Chamado de Blocktopia](CAPITULO-01.md) | Narrativa de chegada, Vila Central, Guilda e mistério |
| [Missão 001 — Um Lar em Blocktopia](MISSAO-001-UM-LAR.md) | Convite aos jogadores e falas para condução manual |
| [Requisitos de construção](REQUISITOS-DE-CONSTRUCAO.md) | Cenários, direção medieval, critérios do lar e recompensa proposta |
| [Scripts planejados](SCRIPTS-PLANEJADOS.md) | Possíveis automações futuras e seus limites; nenhum script novo |
| [Validação](VALIDACAO.md) | Revisão documental e procedimentos futuros de ensaio |

O [plano do Capítulo 1](../PLANO-CAPITULO-01.md) mantém a sequência de preparação, dependências e procedimento de construção. [STATUS](../STATUS.md) concentra evidências e pendências; [IMPLEMENTACAO](../IMPLEMENTACAO.md) concentra detalhes técnicos e operacionais. Este pacote documental não modifica esses estados por inferência.

Para preparar a sessão, revisar contexto → capítulo → missão → requisitos → validação. A aventura começa com condução de um adulto; automações não são pré-requisito.
